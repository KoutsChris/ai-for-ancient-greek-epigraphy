# AI for Ancient Greek Epigraphy - NLP & Machine Learning

Analysis of Ancient Greek inscriptions using Natural Language Processing (NLP), text mining and unsupervised machine learning techniques.

## Overview

This project explores the application of NLP and Machine Learning methods to Ancient Greek epigraphic texts from the ICDAR 2026 Greek Squeezes dataset.

The workflow includes transliteration, word segmentation, vocabulary analysis, named-entity extraction, clustering and topic modeling of historical inscriptions.

## Key Features

* Transliteration of Latin-script transcriptions into Ancient Greek text
* Probabilistic word segmentation using the Viterbi algorithm
* Vocabulary and frequency analysis of Ancient Greek inscriptions
* Named-entity extraction and gender analysis of historical names
* TF-IDF vectorization for text representation
* K-Means clustering for inscription grouping
* LDA topic modeling for thematic discovery
* Comparison of AI-based dating approaches using specialized models and LLMs
